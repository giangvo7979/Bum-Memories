# 🧠 Bum-Memories

A time-based memory system built on Walrus.  
Each epoch stores personal life moments, images, and stories that can never be lost.

---

## ✨ Overview

**Bum-Memories** a place to store my photos, memories, and meaningful moments, built on Walrus.

Instead of a traditional portfolio or gallery, this project transforms life experiences into a nostalgic computer-like interface where memories are organized into folders such as:

- 👨‍👩‍👧 Family
- 😎 Friends
- ✈️ Travel  
- 🍜 Food  
- 📸 Me

Each memory includes:
- 🖼️ Image stored on Walrus (decentralized storage)
- 📝 Personal story or reflection
- 📅 Date / time context

---

## 🌐 Live Website

👉 https://yangbum.wal.app/

## ⛓️ Onchain Concept

This project uses **Walrus decentralized storage** to ensure:

- Memories are permanently stored onchain
- Images and JSON data cannot be lost or deleted
- Each epoch acts as a timestamped memory layer
- Fully decentralized content loading

---

## 💡 Key Features

- 🖥️ Desktop-style UI
- 📁 Folder-based memory organization
- 🖼️ Image gallery loaded directly from Walrus
- 📖 Click-to-view story modal for each memory
- 🌐 Fully decentralized content storage
